## 功能概述

ApiSettingsPage.vue 页面已从简单的API配置页面演变为完整的订阅服务与支付管理中心。该页面提供了三种订阅方式：
- **按次付费套餐包**：灵活的一次性购买方案
- **月度订阅**：适合中等频率使用的用户
- **年度订阅**：高性价比的长期订阅方案

## 优惠策略设计

### 价格展示优化

每个订阅计划都采用了视觉层次分明的价格展示：
```vue
<div class="price-container q-my-sm">

  <div class="current-price">
    <span class="text-h4 text-primary text-weight-bold">¥270</span>

  </div>

  </div>

```

**视觉元素**：
- 原价：小号字体 + 删除线 + 灰色，降低视觉权重
- 现价：大号粗体 + 主题色，突出显示
- 优惠标签：红色渐变背景 + 白色文字 + 表情图标 + 闪光动画

### 动态优惠计算

系统实现了 `calculateDiscount` 函数，根据订阅类型和金额自动计算优惠：
```typescript
const calculateDiscount = (planType: string, originalAmount: number) => {
  // 月度订阅优惠策略
  if (planType === 'monthly') {
    if (originalAmount >= 299) {
      return { discount: 29, reason: '首月立减29元' };
    }
  }
  
  // 年度订阅优惠策略
  if (planType === 'yearly') {
    if (originalAmount >= 2999) {
      return { discount: 299, reason: '年度会员特惠299元' };
    }
  }
  
  // 套餐包阶梯优惠
  if (planType.startsWith('package-')) {
    if (originalAmount >= 699) {
      return { discount: 50, reason: '超值立减50元' };
    } else if (originalAmount >= 468) {
      return { discount: 30, reason: '阶梯优惠30元' };
    } else if (originalAmount >= 168) {
      return { discount: 10, reason: '首次购买立减10元' };
    }
  }
  
  return { discount: 0, reason: '' };
};
```

## 支付流程

### 支付步骤器

使用 Quasar 的 `q-stepper` 组件实现三步支付流程：
1. **确认订单信息**：显示订阅详情、价格摘要
2. **选择支付方式**：提供微信、支付宝、信用卡等支付方式
3. **完成支付**：处理支付结果，更新订阅状态

### 导航按钮设计

支付流程导航按钮经过精心设计，提供清晰的操作指引：
```vue
<q-stepper-navigation class="q-pa-md">
  <div class="row items-center">
    <!-- 上一步按钮 -->
    <q-btn
      v-if="paymentStep > 1"
      flat
      color="grey-8"
      label="上一步"
      icon="arrow_back"
      @click="stepper.previous()"
      no-caps
    />
    
    <q-space />
    
    <!-- 取消按钮 -->
    <q-btn
      flat
      color="grey-8"
      label="取消订单"
      @click="cancelPayment"
      no-caps
      class="q-mr-sm"
    />
    
    <!-- 下一步按钮 -->
    <q-btn
      v-if="paymentStep < 2"
      unelevated
      label="下一步：选择支付方式"
      color="primary"
      icon-right="arrow_forward"
      @click="stepper.next()"
      no-caps
      size="md"
    />
    
    <!-- 确认支付按钮 -->
    <q-btn
      v-else
      unelevated
      label="确认支付"
      color="positive"
      icon="payment"
      @click="processPayment"
      :loading="paymentProcessing"
      no-caps
      size="md"
      class="payment-confirm-btn"
    >
      <template v-slot:loading>
        <q-spinner-dots color="white" />
      </template>
    </q-btn>
  </div>
</q-stepper-navigation>
```

**按钮设计要点**：
- 主次按钮颜色区分（primary、positive、grey-8）
- 图标增强识别性（arrow_back、arrow_forward、payment）
- 文案明确（"下一步：选择支付方式"比简单的"下一步"更具引导性）
- 加载状态处理（loading spinner）
- hover 动画效果（阴影增强 + 上移）

## 总结

订阅与支付功能的设计遵循以下原则：
1. **价格透明**：清晰展示原价、优惠和最终价格
2. **经济激励**：通过视觉强化优惠信息，引导用户下单
3. **操作简便**：三步支付流程，按钮文案明确
4. **视觉吸引**：采用渐变、动画等现代设计元素
5. **响应式**：适配各种屏幕尺寸

这些优化显著提升了用户的订阅转化率和支付体验。
