# 2026-04-14 系统监控与数据导入功能增强

## 日期

2026-04-14

## 概述

本次更新新增系统监控面板、患者批量导入功能、审计日志系统，并对多个核心页面进行 UI 优化和代码重构。

## 新增功能

### 系统监控面板

新增 `SystemMonitorPage.vue` 系统监控页面，提供实时性能指标与操作审计。

**核心指标卡片：**

| 指标 | 说明 |
| :--- | :--- |
| **CPU 负载** | 显示 1m/5m/15m 负载均值与核心数 |
| **内存使用** | 百分比进度条 + 已用/总量展示 |
| **数据库连接池** | 当前池大小/可用/等待连接数 |
| **分析队列** | 运行中/等待任务数/并发上限 |

**功能特性：**
- 自动刷新与手动刷新切换
- 请求量趋势图表（ECharts）
- 审计日志分页查询（支持按用户/操作类型/时间范围筛选）

### 患者批量导入

新增 `PatientImportDialog.vue` 患者批量导入对话框组件，支持 CSV/Excel 文件批量导入患者数据。

**功能流程：**
1. 下载导入模板
2. 拖拽或选择文件上传
3. 预览数据（显示总条数、有效/无效条数）
4. 确认导入

**技术特性：**
- 支持 CSV、Excel 文件（.csv/.xlsx/.xls）
- 最大 10MB 文件限制
- 重复数据检查（身份证号 + 姓名+出生日期联合索引）
- 临时文件自动清理

### 审计日志系统

新增审计日志功能，记录关键操作行为。

**数据模型：**
- `AuditLog` 模型：记录用户 ID、操作类型、资源类型、资源 ID、操作详情、IP 地址、User-Agent

**API 端点：**
- `GET /api/audit/logs` - 审计日志列表（分页、筛选）

**中间件：**
- `auditLogger.js` - 审计日志中间件，支持 `logAudit()` 函数记录操作

## 功能优化

### 影像分析 UI 增强

**StudyDetailPage.vue 优化：**

| 优化项 | 说明 |
| :--- | :--- |
| 诊断结果卡片 | 增强视觉层次感和信息展示 |
| 影像预览控制 | 新增放大、缩小、全屏控制按钮 |
| AI 标注视图 | 实时交互及占位提示 |

| 参数配置面板 | 支持模型选择和灵敏度、置信度阈值调节 |

### 分析进度上限调整

- 分析进度上限从 85% 调整至 90%
- 提升用户体验的进度感知

### 安全加固

- **短信验证码安全**：验证码生成从 `Math.random()` 升级为 `crypto.randomInt()`，消除可预测风险
- **Token 存储加固**：refreshToken 改用 HttpOnly Cookie 存储（`httpOnly: true`，生产环境 `secure: true`），替代 localStorage 方案，防止 XSS 攻击窃取
- **统一错误处理**：新增 `errorHandler.js` 全局错误处理中间件，统一 API 错误响应格式
- **请求日志中间件**：`requestLogger.js` 记录所有请求详情与慢请求警告

### 数据模型扩展

- **Study 模型**：`review_status`（审核状态）、`reviewed_at`（审核时间）、`reviewed_by`（审核人）字段，支持病例医疗审核流程
- **数据库索引优化**：新增审计日志、随访、通知等复合索引，提升高频查询性能
