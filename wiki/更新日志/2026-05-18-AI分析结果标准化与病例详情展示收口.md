# 2026-05-18 AI分析结果标准化与病例详情展示收口

## 变更摘要

本次更新围绕 **AI 分析结果的一致性** 与 **病例详情页展示收口** 两条主线展开，目标是让同一份分析结果在 AI 输出、落库、患者洞察、报告导出与病例详情页之间保持统一口径，并移除不必要的伪数据和重复表达。

核心收益：

- AI 分析结果不再轻易出现“未知”“待补充”“0% 置信度”等可展示但无效的文本
- `risk_level` 的解释链路收敛到统一标准化模块，避免“模型说一套、页面显示一套、报告导出又一套”
- 患者洞察在历史不足时改为“基线建立中 / 即时洞察”，不再伪造趋势或统计结论
- 病例详情页“病变特征识别结果”去掉柱形图和缩略图，最终收敛为 **全宽区域摘要卡**，避免与上方原图/标注图重复

---

## 后端：AI分析结果标准化内核

新增 `server/services/analysisResultNormalizer.service.js` 作为统一结果标准化模块，负责以下能力：

- 归一化 `diagnosis`
- 归一化 `confidence`（兼容 `0-1` 小数与 `0-100` 百分比）
- 归一化 `risk_level / riskLevel`
- 标准化 `recommendations / biomarkers / suspiciousAreas / detailedReport`
- 构建统一的风险展示信息（等级、标签、颜色）

### 接入位置

- `server/services/qwenService.js`
  - AI 原始输出在返回前先标准化
  - 提示词新增更强约束，要求返回结构化、可直接展示的分析结果
- `server/services/analysisService.js`
  - 分析结果落库前统一走标准化内核
  - 不再单独维护一套关键词到风险等级的粗略映射
- `server/routes/analysis-tasks.js`
  - 手动保存/回写分析结果时，也统一走标准化逻辑
- `server/services/reportGenerator.service.js`
  - 服务端 PDF / Word / Excel 导出改为消费标准化后的风险等级、可疑区域、建议与详细报告

### 重要行为调整

- 持久化结果存在 `risk_level` 时优先保留原始等级，不再默认按诊断文本重新升级
- “无法诊断”不再被粗暴覆盖成固定原因；已有明确原因会保留，仅在缺失时补默认说明
- 没有局灶病灶时不再伪造一条“可疑区域”，避免统计和展示误导

## 患者洞察：趋势与评分口径统一

`server/services/patientInsights.service.js` 已接入标准化结果，以下链路改为优先消费归一化后的结果：

- 历史趋势 (`getPatientHistory`)
- 风险画像 (`getPatientRiskProfile`)
- 最新分析摘要 (`getPatientOverview`)
- 疾病进展预警 (`predictDiseaseProgression`)
- 时间线事件 (`getPatientTimeline`)
- 多时段对比 (`crossPeriodComparison`)
- 风险因素分析 (`analyzeRiskFactors`)

### 关键调整

- 历史记录不足时：
  - 趋势字段返回 `baseline` 或 `insufficient`
  - 页面文案显示“基线建立中”或“样本不足”
  - 不再伪造“稳定 / 平稳”结论
- 风险画像中的 `high_risk_ratio / trend / followup_overdue / high_attention` 评分边界已重新收口，避免单一因子过度放大
- 即使没有历史趋势数据，仍可给出“即时洞察 / 基线建议 / 随访建议”

## 前端：病例详情页展示收口

`src/pages/StudyDetailPage.vue` 进行了两轮展示优化，最终方案如下：

### 1. 风险与结果显示

- 前端 `AnalysisResult` 显式增加 `riskLevel`
- `src/stores/analysisStore.ts` 与 `src/utils/studyMappers.ts` 已把后端 `risk_level` 透传到页面层
- 详情页不再主要依赖 `diagnosis` 文本二次猜风险，而是优先消费真实 `riskLevel`

### 2. 病变特征识别结果区

原先这里使用柱形图表达多个离散病灶区域，存在明显问题：

- 看起来像统计图，不像病例判读
- 当数据异步到达或区域较少时，信息表达并不自然
- 与页面上方已有的“原图 + 标注图”双图对比重复

最终收敛为：

- **全宽区域摘要卡**
- 两个区域时自然呈现为双卡片
- 两个以上区域时自动切换为自适应网格
- 没有区域时显示统一空态卡

每张区域卡包含：

- 区域编号
- 大致位置
- 复核优先级
- 简要描述
- 关键特征摘要

### 3. 重点观察区

- 不再直接泄漏 Markdown 原始文本（如 `#`、`*`）
- 也不再展开整段大报告抢占布局
- 改为“清洗 Markdown 后提取 2-4 条短摘要”的紧凑说明卡

## 导出链路同步

前端 `src/utils/pdfGenerator.ts` 同步做了两类调整：

- 风险等级统一通过共享 `riskLevel` 口径或标准推断链消费，不再到处散落局部猜测逻辑
- “可疑区域数”使用真实区域数量，不再因为无病灶兜底说明而显示成 `1`
