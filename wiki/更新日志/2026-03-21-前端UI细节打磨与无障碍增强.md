## 变更摘要

本次更新聚焦**界面细节打磨**与**无障碍（Accessibility）增强**，覆盖认证品牌页、登录页、Dashboard、患者页面、报表页面等多个核心界面，同时对前端代码质量进行了系统性清理。

---

## 核心变更

### 1. 无障碍标签增强（ARIA Label）

为所有图标按钮补充语义化标签，符合 WCAG 可访问性要求：

| 文件 | 变更 |
| :--- | :--- |
| `ThemeToggle.vue` | 主题切换按钮增加 `aria-label="切换主题"` |
| `AnalyzerToolbar.vue` | 6 个图标工具按钮增加对应 ARIA 标签（放大、缩小、重置视图、裁剪、增强、删除等） |
| `PatientInsightsPage.vue` | 返回按钮增加 `aria-label="返回上一页"`，重置按钮增加 `aria-label="重置视图"` |
| `UserAgreementPage.vue` / `PrivacyPolicyPage.vue` | 返回按钮增加 `aria-label="返回上一页"` |
| `FollowUpsPage.vue` | 编辑按钮增加 `aria-label="编辑随访"`，关闭图标按钮增加 `aria-label="关闭"` |
| `LoginPage.vue` / `ApiSettingsPage.vue` / `SettingsPage.vue` / `ProfilePage.vue` / `AiPreferencesPage.vue` | 关闭对话框图标按钮增加 `aria-label="关闭对话框"` |
| `ImageUploader.vue` | 清除文件按钮增加 `aria-label="清除文件"`，清除患者按钮增加 `aria-label="清除患者"` |
| `AuthBrandPanel.vue` | 软著预览关闭按钮增加 `aria-label="关闭对话框"` |
| `StudyDetailPage.vue` | 报告下载按钮增加 `aria-label="下载报告"`，AI分析悬浮按钮增加 `aria-label="打开AI助手"`，导出图表按钮增加 `aria-label="导出图表"` |
| `PatientInsightsPage.vue`（补充） | 返回列表按钮增加 `aria-label="返回患者列表"` |

### 2. 键盘可聚焦样式（:focus-visible）

为可交互卡片元素增加键盘焦点可见样式，提升键盘导航体验：

- `.action-card`（快捷操作卡片）：获得 `:focus-visible` 轮廓样式
- `.notice-item`（通知条目）：获得 `:focus-visible` 轮廓样式
- `.copyright-card--clickable`（软著预览卡片）：获得 `:focus-visible` 样式

### 3. 认证品牌页增强

- 新增极淡网格纹理背景，增加视觉层次感
- 优化多页面样式细节一致性

### 4. 登录页响应式优化

- 针对极窄屏幕（`<420px`）隐藏登录 tab 标签文本，改为仅显示图标
- 解决极窄屏下右侧工作台被截断的问题
- 使用 `q-gutter-y-md` 替代 `q-gutter-md` 避免横向外扩

### 5. Dashboard 数字滚动动画与欢迎语

- 实现数字滚动动画（`useCountUp` composable），统计数据从 0 滚动至目标值
- 新增分时段欢迎语问候（早安/午安/晚安）
- 三个统计卡片使用 `data-target` 属性驱动动画：
  - 今日分析总数：从 0 滚动至 128
  - 高风险病例：从 0 滚动至 12
  - 平均处理时长：从 0 滚动至 1.8 分钟

### 6. ReportsPage 与 PatientsPage 样式优化

- 添加页面级 `body.body--dark` 全局暗色模式覆盖块
- 覆盖表格、输入框、下拉框等组件在暗色模式下的样式
- 统一表格行 hover 样式、对话框标题层级

### 7. 前端代码质量清理

| 文件 | 变更 |
| :--- | :--- |
| `DashboardPage.vue` | 移除 `fetchPendingTasks` 和 `handleTask` 中的大量 debug `console.log`；统一异常捕获语法 |
| `StudyDetailPage.vue` | 移除 20+ 条 debug 日志，保留必要的 `console.error` |
| `UploadPage.vue` | `progressInterval` 改为响应式引用（`ref`），并在 `onBeforeUnmount` 清理定时器，避免内存泄漏 |
| 多个页面 | 移除 TypeScript 非空断言（`!`）的冗余用法 |

---

## 架构影响

- **`useCountUp` composable**：新增数字滚动动画工具函数，通过 `requestAnimationFrame` 读取 `data-target` 属性，支，持小数位数配置
- **定时器管理**：`UploadPage` 的上传进度轮询定时器改为组件级响应式引用，确保组件卸载时正确清理
