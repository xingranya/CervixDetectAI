### 1.3 协议页面返回按钮修复

**位置**:
- `src/pages/UserAgreementPage.vue`
- `src/pages/PrivacyPolicyPage.vue`

**问题描述**：
当用户从弹窗点击"查看完整协议"时，页面通过 `window.open(..., '_blank')` 在新标签页打开。新标签页的 `window.history.length` 通常只有1-2，导致 `router.back()` 行为异常。

**解决方案**：

```typescript
const goBack = () => {
  // 检查是否是从新标签页打开的
  if (window.opener) {
    // 新标签页打开的，直接关闭
    window.close();
  } else if (window.history.length > 2) {
    // 有足够的历史记录，可以返回
    router.back();
  } else {
    // 没有历史记录，跳转到登录页
    void router.push('/login');
  }
};
```

**行为说明**：
- **新标签页打开时** → 直接关闭标签页
- **正常导航时** → 返回上一页
- **无历史记录时** → 跳转到登录页
