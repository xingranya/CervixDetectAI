## 一、新增验证码组件

### 1.1 AliCaptcha.vue 组件

**位置**: `src/components/common/AliCaptcha.vue`

**功能描述**：
封装阿里云 ESA AI 验证码服务，提供统一的验证码调用接口，支持多种验证场景。

**核心特性**：

| 特性 | 说明 |
|------|------|
| 动态加载 | SDK 从阿里云 CDN 动态加载，避免首屏阻塞 |
| 防重复加载 | 检测已存在的 script 标签，避免重复加载 |
| 多场景支持 | 通过 `sceneId` prop 支持不同验证类型 |
| 状态管理 | 内置 loading、error 状态，支持重试机制 |
| 实例隔离 | 通过 `instanceId` 区分多个验证码实例 |

**组件接口**：

```typescript
// Props
interface Props {
  visible?: boolean;    // 是否显示验证码，默认 true
  instanceId?: string;  // 实例ID，默认 'default'
  sceneId?: string;     // 场景ID，空则使用默认场景
}

// Events
emit('success', token: string)  // 验证成功
emit('fail', error: string)     // 验证失败
emit('ready')                   // SDK 加载完成
```

## 二、验证场景配置

### 2.1 场景类型

系统配置了两种验证场景：

| 场景 | 场景ID | 验证类型 | 触发时机 |
|------|--------|----------|----------|
| 登录/注册 | `u1g43fza` | 一点即过 (Smart) | 点击登录/注册按钮前 |
| 发送短信 | `1dynwu1h` | 图像复原 (Puzzle) | 点击获取验证码按钮 |

### 2.2 验证类型说明

**一点即过验证**：
- 智能风险识别，低风险用户点击即可通过
- 高风险用户需完成滑动验证
- 用于登录和注册表单提交前

**图像复原验证**：
- 需要用户完成拼图操作
- 防止自动化脚本滥刷短信接口
- 用于发送短信验证码前

**变更内容**：

1. 添加验证码状态管理：
   ```typescript

   ```

2. 在协议复选框后添加验证码组件：
