## 二、注册页从“平铺大表单”改为“两步向导”

### 2.1 信息架构重构

- Step 1：选择注册方式（工号注册 / 邮箱注册）。
- Step 2：仅展示当前方式必填字段，其他路径字段不渲染。
- “补充资料（可选）”独立折叠，手机号改为资料字段，不作为本页主注册凭据。

### 2.2 业务规则落地

- 工号路径：`hospital + department + entryYear + sequenceNumber + password`。
- 邮箱路径：`email + emailCode + password`。
- 通用可选：`real_name`、`phone`。
- 增加“使用手机号验证码注册”次级入口，跳转 `/login?mode=phone` 走短信通道。

### 2.3 模式切换策略

- 保留分组草稿状态（工号草稿与邮箱草稿分别记忆），避免重复输入。
- 提交时按当前模式组装 payload，避免跨模式字段污染。

## 三、登录页联动增强

## 六、前端调用示例

```ts
// 注册页：手机号验证码注册入口
await router.push({
  path: '/login',
  query: { mode: 'phone' },
});

// 登录页：深链模式解析
const resolveLoginMode = (mode: unknown): 'email' | 'phone' | 'employee' => {
  if (mode === 'email' || mode === 'phone' || mode === 'employee') return mode;
  return 'employee';
};
```
