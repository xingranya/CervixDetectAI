## 一、品牌面板内容体系重构

本轮对认证页左侧品牌展示面板进行了从信息架构到视觉表达的系统性重构，使其从"功能标签罗列"升级为"医疗工作流叙事"。

### 1.1 接口与数据结构变更

- 移除 `BrandRealtimeMetric` 接口（含 `label / value / description / color` 字段）
- 新增 `BrandWorkflowStep` 接口（含 `title / description / icon` 字段）
- `BrandFeatureItem` 移除 `tag` 字段，保留 `icon / title / description`

### 1.2 工作流三步链路

新增 `workflowSteps` 数组，以三步工作流替代旧版实时指标区：

| 步骤 | 标题 | 图标 | 说明 |
|------|------|------|------|
| 01 | 采集与上传 | `upload_file` | 影像与病例信息统一录入 |
| 02 | 分析与复核 | `psychology` | AI 风险提示 + 医生临床复核 |
| 03 | 报告与归档 | `fact_check` | 分析结论、报告导出、随访提醒闭环 |

### 1.3 核心能力卡片重写

四张核心能力卡片全部重写，从技术标签式表达转为临床场景导向：

| 旧版 | 新版 |
|------|------|
| `AI CORE` 智能影像分析 | `speed` 快速风险分层 |
| `WORKFLOW` 病例协同闭环 | `account_tree` 统一协作链路 |
| `REPORT` 结构化报告生成 | `summarize` 结构化报告输出 |
| *(无)* | `track_changes` 过程可追溯 |

### 1.4 文案微调

- 副标题补充"可追溯"关键词：`稳定、可信、可追溯的宫颈筛查辅助工作流`
- `onBeforeUnmount` / `computed` 替换为 `onUnmounted` / `ref`，简化依赖

## 二、认证布局背景动效升级

### 2.1 全局微光背景

`AuthSplitLayout` 静态渐变背景替换为带 `background-size: 200% auto` 的微光动画：

- 新增 `@keyframes global-bg-shimmer`（5s ease-in-out 交替）
- 色阶从三段式改为五段式（`#f0f9ff → #e0f2fe → #bae6fd → #e0f2fe → #f0f9ff`），中间色更饱和

### 2.2 网格背景平移动画

- 动态网格背景新增 `@keyframes mesh-pan`（40s 线性循环，-40px 偏移）
- 网格产生缓慢漂移感，避免完全静止的贴图观感

### 2.3 工作区面板透明化

- 桌面端工作区面板从 `backdrop-filter: blur` 磨砂玻璃改为 `background: transparent`
- 解决旧版半透明叠加在深色模式下色彩偏移的问题

### 2.4 暗色模式同步

- 暗色背景渐变同步改为五段式 + shimmer 动画
- 色阶适配暗色系：`#020617 → #0c1525 → #1e293b → #0c1525 → #020617`

## 三、工作区外壳细节打磨

### 3.1 副标题标签降权

- 图标从 `shield` 改为 `info`，去掉"安全防护"暗示，回归信息提示定位
- 标签样式从胶囊形（`border-radius: 999px`）改为圆角矩形（`8px`）
- 背景从品牌蓝渐变降为中性灰半透明：`rgba(248, 250, 252, 0.6)`
- 文字颜色从品牌蓝降为次要文本色

### 3.2 暗色模式简化

- 暗色标签移除独立蓝色渐变背景，统一为 `rgba(255, 255, 255, 0.02)`
- 图标不再单独配色，跟随 `currentColor` + `opacity: 0.75`

### 3.3 布局溢出修复

- 品牌面板溢出策略从 `overflow: visible` 改为 `overflow-y: auto; overflow-x: hidden`
- 解决移动端极端宽度下内容溢出不可滚动的问题
