## 一、患者模型字段扩展

### 变更内容

**Patient.js模型新增以下字段**：

| 字段名               | 类型       | 说明                                                                                  | 默认值 |
| -------------------- | ---------- | ------------------------------------------------------------------------------------- | ------ |
| `sexual_history`     | ENUM       | 性生活史（none, regular, irregular, multiple_partners, early_sexual_activity, other） | 'none' |
| `medical_card_no`    | STRING(50) | 医保卡号                                                                              | -      |
| `emergency_relation` | STRING(50) | 紧急联系人关系                                                                        | -      |
| `allergy_history`    | TEXT       | 过敏史（原allergies字段重命名）                                                       | -      |
| `family_history`     | TEXT       | 家族病史                                                                              | -      |
| `notes`              | TEXT       | 备注信息                                                                              | -      |

**外键约束更新**：

- `created_by` 字段的 `onDelete` 策略从 `RESTRICT` 改为 `SET NULL`
- 允许用户账户删除，患者记录保留但 `created_by` 设为 NULL

## 二、病例管理页面功能增强

### 变更内容

**StudiesPage.vue新增功能**：

1. **Tab切换筛选**
   - 全部病例、已完成、处理中、失败四个Tab
   - 实时显示各状态病例数量（带彩色badge）
   - 自动统计 `completedCount`、`processingCount`、`failedCount`

2. **患者筛选功能**
   - 新增 `q-select` 下拉选择器
   - 自动提取所有病例中的唯一患者列表
   - 支持 `clearable` 快速清除筛选
   - 配合 `person` 图标提升用户体验

3. **多维度搜索**
   - 支持患者姓名模糊搜索
   - 支持患者ID精确匹配
   - 支持检查方式（modality）搜索
   - 防抖动设置（debounce=300ms）

4. **组合筛选逻辑**
   ```
   所有病例 → Tab状态过滤 → 患者ID过滤 → 关键词搜索 → 最终结果
   ```

## 四、订阅与支付界面优惠策略优化

### 变更内容

**ApiSettingsPage.vue重大优化**：

1. **价格展示优化**
   - 清晰显示原价（删除线 + 灰色小字）
   - 突出现价（大号粗体 + 主题色）
   - 红色渐变优惠标签（带🎫图标 + 闪光动画）

2. **动态优惠计算**
   - 月度订阅：满299元立减29元
   - 年度订阅：满2999元特惠299元
   - 套餐包阶梯优惠：10元、30元、50元

3. **支付摘要展示**
   - 订阅费用行（显示原价）
   - 优惠行（绿色渐变背景 + 图标 + 原因说明）
   - 分隔线
   - 应付总额（大号粗体）
   - 节省金额chip（橙色 + celebration图标）

4. **导航按钮美化**
   - 上一步：flat样式 + arrow_back图标
   - 下一步：primary色 + 明确文案"下一步：选择支付方式"
   - 确认支付：positive色 + payment图标 + 特殊样式类
   - hover动画：阴影增强 + 上移效果

## 技术亮点

### 1. 数据模型设计改进

- **字段语义化**：`allergies` → `allergy_history`，更清晰
- **外键策略优化**：`RESTRICT` → `SET NULL`，平衡数据完整性与灵活性
- **医疗数据完善**：新增性生活史、家族病史等关键医疗信息

### 2. 前端组件优化

- **多维筛选**：Tab + 下拉选择 + 搜索框，三层过滤机制
- **计算属性链式处理**：`filteredStudies` 清晰的数据流转
- **防抖优化**：搜索框 debounce=300ms 减少不必要的渲染

### 3. 用户体验创新

- **本地化**：中文日期选择器
- **视觉引导**：渐变、动画、阴影等现代设计元素
- **经济激励**：优惠信息的视觉强化（红色标签、闪光效果）

### 4. 代码质量
