一、软件简介

CervixDetectAI 宫颈癌智能筛查系统是一款基于人工智能技术的医学影像
分析软件，专门用于宫颈细胞学图像的智能分析与诊断。系统采用阿里云
通义千问大模型作为AI引擎，结合专业的病理学知识库，为医生提供准确
的诊断参考和辅助决策支持。

二、主要功能

1. 用户管理
   - 邮箱注册登录
   - 手机短信验证登录
   - 用户权限管理（管理员、医生、普通用户）
   - 个人信息管理

2. 患者管理
   - 患者信息录入
   - 患者档案查询
   - 医疗历史记录

3. 病例管理
   - 病例创建与编辑
   - 医学影像上传
   - 病例状态跟踪
   - 历史记录查询

4. AI智能分析
   - 宫颈细胞学图像分析
   - 自动诊断分类
   - 置信度评估
   - 风险等级判定
   - 生物标志物推测（HPV、p16、Ki67）
   - 临床建议生成

5. 报告管理
   - 分析报告生成
   - 报告查看与导出
   - 历史报告管理

三、系统要求

1. 服务器端要求

操作系统：
- Windows Server 2016 及以上

- macOS 10.14+

软件环境：
- Node.js 16.x 或更高版本
- MySQL 5.7+ 或 MySQL 8.0+
- npm 7.x 或更高版本

硬件配置：
- CPU: 4核及以上
- 内存: 8GB及以上
- 硬盘: 100GB及以上可用空间
- 网络: 稳定的互联网连接

2. 客户端要求

浏览器支持：
- Google Chrome 90+（推荐）
- Microsoft Edge 90+
- Firefox 88+
- Safari 14+

屏幕分辨率：
- 最低: 1366×768
- 推荐: 1920×1080及以上

网络要求：
- 宽带连接: 10Mbps及以上
- 稳定的网络环境

3. 第三方服务

必需服务：
- 阿里云通义千问 API 访问权限
- MySQL 数据库服务

可选服务：

四、安装步骤

1. 环境准备

步骤1：安装 Node.js
访问 https://nodejs.org 下载并安装 Node.js 16.x 或更高版本。
安装完成后，在命令行验证：
  node --version
  npm --version

步骤2：安装 MySQL
下载并安装 MySQL 5.7+ 或 8.0+。
创建数据库：
  CREATE DATABASE cervix_detect_ai 
  CHARACTER SET utf8mb4 
  COLLATE utf8mb4_unicode_ci;

步骤3：获取源代码
将系统源代码解压到指定目录，例如：
  Windows: D:\CervixDetectAI
  Linux: /opt/CervixDetectAI

2. 后端部署

步骤1：安装依赖
进入后端目录：
  cd server
  npm install

步骤2：配置环境变量
在 server 目录下创建 .env 文件，配置以下参数：

# 数据库配置
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=cervix_detect_ai

# JWT密钥
JWT_SECRET=your-secret-key-change-in-production
JWT_REFRESH_SECRET=your-refresh-secret-key

# 服务器端口
PORT=3000

# 通义千问API配置
QWEN_API_KEY=your_qwen_api_key
QWEN_API_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
QWEN_MODEL=qwen-vl-max

4. 生产环境部署（Nginx）

步骤1：安装 Nginx
根据操作系统安装 Nginx Web 服务器。

步骤2：配置 Nginx
创建配置文件 /etc/nginx/sites-available/cervixdetectai：

server {
    listen 80;
    server_name your_domain.com;
    
    # 前端静态文件
    root /path/to/dist/spa;
    index index.html;
    
    # 前端路由
    location / {
        try_files $uri $uri/ /index.html;
    }
    
    # API反向代理
    location /api/ {
        proxy_pass http://localhost:3000/api/;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}

步骤3：启用配置并重启
  ln -s /etc/nginx/sites-available/cervixdetectai /etc/nginx/sites-enabled/
  nginx -t
  systemctl restart nginx

步骤4：使用 PM2 管理后端进程
安装 PM2：
  npm install -g pm2

启动后端服务：
  cd server
  pm2 start index.js --name cervixdetectai-backend
  pm2 save
  pm2 startup

五、用户管理功能

1. 用户注册

支持两种注册方式：

(1) 邮箱注册
- 访问注册页面
- 输入邮箱地址
- 设置密码（至少6位）
- 填写姓名、手机号（可选）
- 点击"注册"按钮
- 注册成功后自动登录

(2) 手机号注册
- 访问登录页面
- 切换到"手机登录"标签
- 输入手机号
- 点击"获取验证码"
- 输入收到的6位验证码
- 点击"登录/注册"
- 系统自动判断：如手机号未注册则自动完成注册

2. 用户登录

支持三种登录方式：

(1) 邮箱密码登录
- 输入注册时使用的邮箱
- 输入密码
- 可选择"记住我"保持登录状态
- 点击"登录"按钮

(2) 手机验证码登录
- 切换到"手机登录"标签
- 输入手机号
- 获取并输入验证码
- 点击"登录/注册"

(3) 自动登录
系统会记录登录状态，下次访问时自动登录（7天有效期）。

3. 密码找回

- 点击"忘记密码"
- 输入注册邮箱或手机号
- 通过验证码重置密码

八、AI智能分析功能

1. 提交分析任务

方式一：上传时自动分析
- 在上传图像时，勾选"自动开始AI分析"
- 系统自动创建分析任务

方式二：手动触发分析
- 进入病例详情页
- 点击"开始AI分析"按钮
- 确认分析参数
- 点击"确定"开始分析

2. 分析进度跟踪

- 分析任务启动后，显示实时进度：
  * 等待中 (0%)
  * 图像预处理 (10%)
  * AI模型分析 (30%-90%)
  * 结果生成 (90%-100%)
- 预计分析时间：30-60秒

3. 分析结果查看

分析完成后，系统自动显示结果，包括：

(1) 诊断结论
显示AI判断的诊断分类，例如：
- NILM（正常）
- ASC-US（意义不明确的非典型鳞状细胞）
- LSIL（低度鳞状上皮内病变）
- HSIL（高度鳞状上皮内病变）
- SCC（鳞状细胞癌）

(2) 置信度
以百分比形式显示AI对诊断结果的信心程度：
- 90%以上：高可信度
- 70%-90%：中等可信度
- 70%以下：低可信度，建议人工复核

(3) 风险等级
根据诊断结果自动判定风险等级：

- 低风险：绿色标识
- 中风险：橙色标识
- 高风险：深橙色标识
- 极高风险：红色标识

(4) 可疑区域描述
标注图像中发现的异常区域，包括：
- 区域位置
- 细胞形态特征
- 异常程度

(5) 生物标志物评估

十六、附录

附录A：诊断分类说明

根据TBS分类系统，宫颈细胞学诊断分类包括：

1. NILM (Negative for Intraepithelial Lesion or Malignancy)
   - 中文：未见上皮内病变或恶性病变
   - 风险等级：低
   - 建议：常规随访

2. ASC-US (Atypical Squamous Cells of Undetermined Significance)
   - 中文：意义不明确的非典型鳞状细胞
   - 风险等级：中
   - 建议：HPV检测或6个月后复查

3. ASC-H (Atypical Squamous Cells, Cannot Exclude HSIL)
   - 中文：不能除外高度鳞状上皮内病变的非典型鳞状细胞
   - 风险等级：高
   - 建议：阴道镜检查

4. LSIL (Low-grade Squamous Intraepithelial Lesion)
   - 中文：低度鳞状上皮内病变
   - 风险等级：中-高
   - 建议：阴道镜检查或密切随访

5. HSIL (High-grade Squamous Intraepithelial Lesion)
   - 中文：高度鳞状上皮内病变
   - 风险等级：高
   - 建议：立即阴道镜检查和活检

6. SCC (Squamous Cell Carcinoma)
   - 中文：鳞状细胞癌
   - 风险等级：极高
   - 建议：立即转诊专科治疗

附录C：文件格式要求

医学影像文件要求：

1. 支持的图像格式
   - JPEG (.jpg, .jpeg)
   - PNG (.png)
   - TIFF (.tiff, .tif)

2. 图像质量要求
   - 分辨率：建议2000×2000像素以上
   - 色彩：支持RGB彩色和灰度
   - 清晰度：确保细胞结构清晰可辨
   - 文件大小：不超过10MB

3. 图像采集建议
   - 使用专业医学影像设备
   - 适当的光照条件
   - 避免过度曝光或曝光不足
   - 聚焦准确，避免模糊
   - 包含足够的细胞样本
