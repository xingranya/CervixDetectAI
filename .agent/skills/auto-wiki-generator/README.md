# Auto Wiki Generator 使用指南

## 快速开始

### 安装和配置

该技能已经集成到您的Qoder环境中，无需额外安装。

### 基本使用

在聊天中输入以下任一命令即可触发文档生成：

```
更新wiki
生成wiki文档
自动更新项目文档
```

## 功能特性

### 🔄 自动扫描
- 递归扫描项目目录结构
- 识别前端(src/)和后端(server/)代码
- 分析文件类型和依赖关系

### 📊 智能变更检测
- 检测最近7天的文件修改
- 识别新增、修改、删除的文件
- 精准定位变更影响范围

### 📝 标准文档生成
- 生成符合项目现有风格的markdown文档
- 包含Mermaid图表和代码示例
- 自动添加文件引用标签

### 🔧 增量更新
- 只更新变更部分，保持其他内容不变
- 智能合并新增和修改的内容
- 支持文档版本控制

## 生成的文档类型

### 1. 项目结构文档
- `wiki/项目目录结构/项目目录结构.md`
- 详细描述前后端目录组织
- 包含文件统计和结构图

### 2. 架构设计文档
- `wiki/前端架构/前端架构.md`
- `wiki/后端架构/后端架构.md`
- 技术栈说明和组件关系

### 3. API参考文档
- `wiki/API参考/API参考.md`
- 接口端点列表和使用示例
- 请求/响应格式说明

### 4. 数据库设计文档
- `wiki/数据库设计/数据库设计.md`
- 表结构和ER关系图
- 索引策略和性能优化

## 配置选项

### 扫描配置
```javascript
{
  // 排除的目录模式
  "exclude_patterns": [
    "node_modules/**",
    ".git/**",
    "dist/**"
  ],
  
  // 处理的文件扩展名
  "file_extensions": [
    ".js", ".ts", ".vue", ".sql"
  ],
  
  // 最大扫描深度
  "max_depth": 10
}
```

### 更新配置
```javascript
{
  // 回溯天数
  "lookback_days": 7,
  
  // 是否备份原文档
  "backup_original": true,
  
  // 增量更新阈值
  "incremental_threshold": 0.3
}
```

## 最佳实践

### 1. 定期更新
建议每周执行一次文档更新，保持文档与代码同步。

### 2. 重点关注
- 核心功能模块的变更
- API接口的修改
- 数据库结构的调整

### 3. 质量检查
- 验证生成的引用链接是否有效
- 检查图表是否正确显示
- 确认代码示例的准确性

## 故障排除

### 常见问题

**Q: 生成的文档格式不正确**
A: 检查项目中是否包含示例文档作为参考模板

**Q: 某些文件未被正确分析**
A: 确认文件路径是否在扫描范围内，检查文件权限

**Q: 图表无法正常渲染**
A: 验证Mermaid语法，检查图表数据完整性

## 扩展开发

### 自定义模板
可以在 `templates/` 目录下添加自定义文档模板。

### 集成CI/CD
可配置为在代码推送时自动执行文档更新。

### 多项目支持
通过配置可以同时管理多个项目的文档生成。
