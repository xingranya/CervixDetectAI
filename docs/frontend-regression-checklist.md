# 前端回归检查清单

## 病例列表

- 打开“数据报表”页后，列表正常加载。
- 切换 `全部病例 / 已完成 / 处理中 / 失败` 时，URL 查询参数同步变化。
- 输入关键词后刷新页面，筛选状态仍能恢复。
- 从患者页面携带 `patient_id` 跳转到病例列表时，患者筛选自动生效。
- 切换分页与每页条数后刷新页面，分页状态仍能恢复。
- 删除病例后，列表局部更新且当前 URL 状态不丢失。
- 已完成病例可正常触发 PDF 下载；无结果病例会收到正确提示。

## 主布局与通知中心

- 顶部通知铃铛能正确显示未读数。
- 打开通知面板后可以正常加载通知列表。
- 单条“标记已读”后，未读数同步减少。
- “全部已读”后，未读数归零且列表状态同步更新。
- 从通知跳转病例或随访页面时，路由行为正确。
- 用户菜单中的“个人资料 / 设置 / 退出登录”行为正常。

## AI 与偏好设置

- 页面首次进入时能加载本地已保存配置。
- “保存引擎配置”后刷新页面，模型与阈值仍保持。
- “恢复默认”后，AI 引擎配置恢复默认值。
- “保存全部偏好设置”后刷新页面，通知、报告、安全、账单配置保持。
- “恢复默认设置”后，偏好配置恢复默认值。

## 套餐订阅

- 套餐切换、推荐套餐展示与右侧订阅状态卡正常显示。
- 打开支付弹窗后，所选套餐、金额、支付方式信息正确。
- 完成演示支付后，订阅状态与权益卡片更新。
- 软件著作权证书预览可正常打开与关闭。

## 静态检查

- 执行 `npm run typecheck`
- 执行 `npm run lint`
